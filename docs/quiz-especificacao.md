# Titulo do documento

## 1. Contexto

Dentro do diretório "dashboard", criei um arquivo chamado "quiz.html" para que seja possível eu criar o meu quiz de personalidade, mas existe um problema, este quiz é de erros e acertos, isso faz com que o quiz de personalidade não funcione da forma que deveria funcionar.

Percebendo isso, preciso que refatore as perguntas e as respostas para que este quiz se torne um quiz de personalidade sobre hora de aventura.

## 2. Objetivo

O objetivo é fazer um quiz de personalidade (refatorando o "quiz.html") sobre hora de aventura onde após o usuário finalizar ele será relacionado à um personagem.
Sendo estes personagens:
- "Finn";
- "Jake";
- "Princesa Jujuba";
- "Marceline";
- "BMO";
- "Rei Gelado/Simon Petrikov".

## 3. Escopo
 
- **Dentro do escopo:** funcionalidades e recursos que serão implementados:
- Refatoração do sistema de quiz no "quiz.html" para virar um quiz de personalidade;
- Fazer as perguntas que se relacionam aos personagens;
- Quiz deve conter 10 perguntas.

- **Fora do escopo:** funcionalidades e recursos que não serão contemplados:
- Não alterar nenhuma estilização do site.



## 4. Funcionalidades

As funcionalidades do quiz irão se manter, apenas faça a refatoração para que vire um quiz de personalidade.

## 5. Regras de negócio

A cada alternativa que o personagem for marcando, deve ser adicionado tantos pontos para tal personagem.
Ao final, deve somar os pontos de cada personagem, o personagem que tiver mais pontos será relacionado ao usuário.

## 6. Interface

Não faça nenhuma alteração na interface, apenas altere as perguntas e refatore o sistema para que vire um quiz de personalidade.

## 7. Critérios de aceitação


- Funcinar quando o comando "npm start" for executado;
- Personagem sendo relacionado ao usuário;
- O quiz conseguir ser realizado do início ao fim sem nenhum erro;
- O quiz deve conter 10 perguntas.
